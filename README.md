# AI Memory Museum

Standalone spatial archive prototype where AI curates project artifacts into a navigable exhibition rather than a folder or search result list.

## Run locally

```bash
corepack pnpm install
corepack pnpm dev
```

Open http://localhost:3104.

## Quality checks

```bash
corepack pnpm typecheck
corepack pnpm lint
corepack pnpm build
```

The application is fully self-contained and does not import code from the original monorepo or sibling projects.
